Scroll down & up 👇

Scroll down and the blue header slides up out of view. Scroll up (even a little) and it slides back. This is the classic mobile app-bar behavior, animated with transform so it stays smooth in every browser.

Why this works everywhere

Headroom animates transform, not height. Height animation re-lays-out every frame and breaks/janks across browsers. Transform is GPU-composited, so no layout reflow — reliable on MacBook Chrome, mobile Safari, everything.

How it's wired

One CDN script tag, then var hd = new Headroom(document.getElementById('hd')); hd.init();. That's the whole library call.
